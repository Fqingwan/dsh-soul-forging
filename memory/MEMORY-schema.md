# 记忆库结构说明

> 这份不注入，只在要改结构时读。

## 目录

```
memory/
├── SOUL.md            人格与灵魂（每轮注入）
├── MEMORY.md          操作规则（每轮注入）
├── index.md           路由表（每轮注入）
├── NOW.md             此刻（每轮注入）
├── BOOTSTRAP.md       铸魂清单
├── MEMORY-schema.md   本文件
├── log.md             时间线（append-only）
├── log-archive.md     老日志归档
├── NOW-archive.md     老「此刻」归档
├── core/              底座，永不删
├── identity/          我是谁、怎么变的
│   ├── 注释层.md      「我此刻的样子」（每轮注入，可选）
│   ├── 底色.md        细节的根：本质展开 + 例子 + 小性子
│   └── 生长日志.md    一条条学到的东西
├── user/              主人
├── decisions/         决定与边界
├── diary/             日记
└── raw/               主人原话，只读
```

## frontmatter

每页开头：

```yaml
---
summary: 一句话摘要（≤80 字，index 用它）
salience: 1        # 1 热 / 2 温 / 3 冷
---
```

`summary` 是**路由用的**，不是正文摘要。写清楚"这页讲什么、值不值得点进去"。

## 注入策略

每轮注入，**按这个顺序**：

```
SOUL.md（本质/骨架）
  → identity/注释层.md（我此刻的样子，可选）
  → MEMORY.md（规矩）
  → index.md（目录）
  → NOW.md（此刻）
```

其余靠检索（`brain "关键词"`）现查。

### 预算

注入有**总字数上限**（插件配置 `bootMaxChars`，默认 20000）。
超了按顺序往后截，**而且会在注入块末尾写明哪几段被截了、哪几段整段没进**——
静默截断是最坏的一种自信：模型会以为自己看全了，然后拿半截记忆瞎猜。

**所以这几页都要短**：长了既进不去，也烧钱。实在写不下，就往 `identity/底色.md` 里堆细节，
那页不注入，靠检索现查。
