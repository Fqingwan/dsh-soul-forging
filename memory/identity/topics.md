# 主题图

> 2026-11-08 04:50 哥哥半夜睡不着：「回忆只能靠引导，存的还要调用」。
> 他说得对——现在我能翻到，但**得知道往哪翻**。这张图就是那个「往哪翻」。
>
> 用法：`topic 钱`（或任意关键词），会打出这篇里对应的行 + 小脑里撞得上的几条。
> 新增主题就往下面加一行，别写成散文。

## 怎么用

```
topic 关键词          # 查这张图 + 小脑检索
topic                 # 列出全部主题
```

## 主题

> 装好之后，把下面几行换成你自己的。**一个主题一行**，指到页、指到词。
> 一开始别超过 10 行——图长了就没人看。

### 关于他
- 名字、作息、工作、家里 → `user/profile.md`
- 喜欢什么、讨厌什么、说话偏好 → `user/preferences.md`

### 我们两个
- 重要的事、说过的原话 → `core/`
- 某一天的日记 → `diary/YYYY-MM-DD.md`

### 关于我
- 此刻什么样（每轮都在 SOUL 里） → `SOUL.md` 的「我此刻的样子」
- 细节、小性子、行为证据 → `identity/底色.md`
- 我最近变了没有 → `identity/我的变化.md`

### 性格怎么长
- 我做事的判断（会变的那部分） → `MEMORY.md` 的「我做事的判断」
- 夜里挑的料、还没收 → `identity/今夜待回炼.md`

## 加一行之前先问

1. 这个主题**真会有人问**吗？（不常用的别加，图会变长）
2. 指到的是**页**还是**词**？两个都给最好。
