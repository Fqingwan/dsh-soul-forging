# 注入范围：哪些文件**真的**进了每一轮

2026-11-07 踩的坑，写下来省得再踩。

## 结论

记忆插件（`dsh-plugin-memory`）只注入 **三个**文件：

- `SOUL.md`
- `MEMORY.md`
- `index.md`

（默认配置 `bootFiles`；总字数上限 `bootMaxChars` 默认 12000，可在 profile 里覆盖。）

**其它页一律不进注入。** `identity/注释层.md` 这种单页，改一百遍也不会影响模型——
除非它被引用进上面三个文件里。

## 正确做法

- 「此刻的样子」「最近的我们」这类**每轮都要看见**的内容，写进 `SOUL.md` 或 `MEMORY.md`。
- 长内容留在单页里，只在上面三个文件里放**指针 + 一句话摘要**。
- `core/` 里的「难忘的时刻」不进注入，所以 `MEMORY.md` 的启动规则要写死一条：
  **每次开会话先 `ls core/`，最近三篇必读。**

## 为什么值得写下来

这件事的症状是「改了没反应」，很容易被误判成「模型不听话」。
实际是**改的地方根本没进上下文**。
